# Text and translations

Foreman's web UI is shown in eight languages (SPEC 22). This file is the
single place for the rules every translator and every writer of UI text
follows: which languages, which word for each term, how to address the
user, and how to add a string. A glossary entry here beats a translator's
own taste.

The translations are made by AI and reviewed by a second AI pass before
an epic merges (SPEC 22.6). They can still be wrong. Corrections are
welcome as GitHub issues; please name the language, the page and the
better wording.

## 2. Where the glossary comes from

Where Factorio has its own translation of a term, the glossary uses it,
so a player sees the same word in the game and in Foreman. The official
words below were read from the locale files of the game image
`factoriotools/factorio:2.1.24` (`core/locale` and `base/locale`; the
simplified Chinese file is `zh-CN`, the Spanish file `es-ES`).

Factorio has no word for some terms Foreman needs: world, snapshot, stop,
roll back, setup, disk space and the like. For those, the glossary gives
the usual word in software in that language. They are marked with an
asterisk (\*) in the table. A reviewer may change a starred word with a
reason; an unstarred word changes only if the game's own wording changes.
The Russian "загрузить" for upload is starred because the game's
"выгрузить" is used there in a different sense. The Russian "учётная
запись" for account is starred because it is the usual word in Russian
software for a login to a service.

The glossary lists the base form (the infinitive, or the noun in the
singular). Inflect it as the sentence needs. Notes:

- German: Factorio uses "die Mod", feminine. Keep that gender.
- Russian: Factorio's own "Выход из системы" is a noun. Buttons use the
  verb "Выйти".
- Simplified Chinese: Factorio uses "退出" for sign out, which also means
  quit, so Foreman writes "退出登录".
- French: Factorio says "lancer" and "démarrer" for start; Foreman uses
  "démarrer" everywhere.
- Spanish: Factorio says "guardado" and "partida guardada"; Foreman uses
  "partida guardada".
- Polish: Factorio uses "modyfikacja" in full. Keep it in full.
- Russian: "загрузить" is for upload only. The game image and other
  downloads use "скачать".
- Chinese: the active world is "活动世界", never "当前世界". Loading a
  save is "加载", never "载入".
- Polish: Foreman is declined like a Polish noun (Foremana, w Foremanie)
  in every file. Czech does the same (Foremanu, ve Foremanu).
- Czech: the game image is "obraz", never the English "image".
- German: Foreman's log is "Protokoll", an operation is "Vorgang", and a
  snapshot label is "Bezeichnung".

## 4. Do not translate

Leave these exactly as written, in every language:

- Foreman and Factorio.
- RCON, Docker, SSE, OIDC, MCP, API and similar protocol and product
  names.
- Space Age in German, Russian, Spanish and Czech, where Factorio keeps
  the English name. Use the official name in Chinese (太空时代), French
  (l'Ère spatiale) and Polish (Era Kosmosu), as the table shows.
- Names of mods, as the mod portal writes them.
- File and folder names, such as `world.json`, and environment variable
  names.
- World names, snapshot labels and player names, which people typed.
- Text relayed from Factorio: log lines, console output and crash
  reasons. Mark a block of it `lang="en"` (SPEC 22.3).
- Version numbers, ports and other values.

## 5. How the user is addressed

One rule per language, chosen to match how software in that language
usually speaks. Do not mix forms within a language.

| Language | Rule |
|---|---|
| German | Informal du ("Gib deinen Namen ein"), as Factorio does. |
| Russian | Formal вы, with a lower-case "вы" inside a sentence. |
| Simplified Chinese | Neutral. Avoid the pronoun; write the sentence so none is needed. |
| French | Formal vous. |
| Spanish | Informal tú, as Factorio does ("Selecciona"). Use the imperative or the second person singular, never "usted". |
| Polish | Neutral and impersonal. Buttons use the imperative, as Polish software does ("Zapisz", "Usuń"). Sentences use impersonal wording ("Nie można uruchomić serwera"); never "Pan", "Pani" or "ty". |
| Czech | Neutral and impersonal. Buttons use the infinitive, as Czech software does ("Uložit", "Smazat"). Sentences use impersonal wording ("Server se nepodařilo spustit"); never "ty" or "vy". |

Buttons are short commands, not sentences. Use the same form for every
button in a language.

## 6. Writing rules

These apply to the English source first, and to every translation.

- Plain words, sentence case, no exclamation marks (docs/DESIGN.md,
  section 9).
- Write whole sentences. Never build a sentence from pieces, such as
  "Delete" plus a name plus "?" in three keys. Word order differs by
  language, so one key holds the whole message with placeholders.
- One count per message. A message that counts two things ("3 saves and
  2 snapshots") is two messages shown together, not one message with two
  plurals.
- A message that counts has exactly the plural forms whole numbers need
  in its language (SPEC 22.4): English, German, Spanish and French one and
  other; Russian and Polish one, few and many; Czech one, few and other;
  Chinese other only. Forms for fractions only are not written. The check
  names any missing form.
- Keep placeholders such as `{world}` and `{count}` exactly as written.
  Do not translate, rename, split or reorder their braces. Move them
  within the sentence if the grammar needs it.
- Catalogue values hold no HTML. A link inside a sentence is a separate
  key that the template places.
- No text in CSS. A label that must come from a style sheet takes it from
  a `data-` attribute that the template fills.
- Leave room for text about 40 percent longer than English: no fixed
  widths on buttons, tables or headings. German, Russian and French run
  longest. Every page must still work at 320 px (SPEC 22.7, 17.2).
- Numbers, sizes, dates and durations come from the server or the page's
  formatter, never typed into a value (SPEC 22.4).
- A name a person typed is shown as written, whatever the language.

## 7. Adding or changing a string

1. Add the key to `internal/i18n/locales/en/<area>.json`. Keys are dotted
   ids such as `server.start.button`, not English sentences. The areas
   are `common`, `accounts`, `server`, `worlds` and `js`.
2. Add the same key to the other seven languages' file for that area,
   written with this glossary and address rules. A plural value is an
   object of CLDR categories using `count`.
3. Refresh `translated.json` with `make i18n-hash`. It records a short
   hash of the English text each translation was made from. When English
   changes, `make verify` fails until the other seven are rewritten and
   the hash is refreshed.
4. Run `make verify`. It fails on hard-coded text, a key missing from a
   language, an unused key, mismatched placeholders or plural forms, and
   a stale translation (SPEC 22.5).
5. A second agent reviews every new or changed translation against this
   file before the change merges (SPEC 22.6).

Changing a glossary word here means rewriting every string that uses it,
in the same change.
