# Brand images

- `foreman-logo.webp` and `foreman-wordmark.webp` are the full-size
  reference masters. Keep them as the source for new sizes; do not display
  them.
- `foreman-wordmark-800.webp` is the 800 px wordmark that the top-level
  README shows.
- The app's favicon is the flat design at 16 px and the rusty logo at 32 px
  and up (the owner prefers the rusty logo wherever it reads). The files
  are in `internal/web/static/icons/`.
